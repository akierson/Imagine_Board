# Purpose

Imagine Board is a Krita plugin to browse images and creates reference mood boards.

# Features

* Display Modes ( Preview, Grid, Reference )
* File Explorer ( Preview, Grid, Drive )
* Slideshow
* Color Picker
* Grid Bookmarks
* Grid Search ( Null, Copy )
* Grid Modify ( Fix, Pre-multiply )
* Reference Boards ( File(EO), Link(KRA) )
* Color ( Analyse, LUT )
* Batch processing ( Keyenter, Reorder )
* Support to various File Formats ( Images, Animation, Compressed, Krita, Internet )
* Read ![wiki](https://github.com/EyeOdin/imagine_board/wiki) for more information
* How to ![install a plugin](https://github.com/EyeOdin/imagine_board/wiki/Plugin-Instalation)
* Requires Krita 6 ( PyQt6 ). Krita 5 ( PyQt5 ) is not supported by this version

# Install from this fork

1. Clone this repository (the `pyqt6` branch).
2. Copy the `imagine_board` folder and `imagine_board.desktop` into Krita's `pykrita` folder (Krita: Settings > Manage Resources > Open Resources Folder).
3. Enable the plugin in Krita: Settings > Configure Krita > Python Plugin Manager.

Krita 5 ( PyQt5 ) users: use the [original project](https://github.com/EyeOdin/imagine_board) instead.
